# 购票辅助手机使用说明

> 给第一次使用的朋友：照着下面几步操作就可以，不需要懂技术。

## 它能帮你做什么

购票辅助会在你**手动打开大麦并点击悬浮“开始”以后**，按演出日期和票档价格识别页面，
并在页面完全匹配时执行有限的点击。

它不会：

- 自动打开大麦。
- 保存大麦账号、密码、身份证、手机号或银行卡资料。
- 绕过验证码、登录、风控或设备验证。
- 自动付款。

进入收银台以后，辅助会停止，付款必须由你自己确认和完成。

## 使用前先准备

1. 手机上已经安装并登录大麦。
2. 在大麦中提前设置好目标场次、票档、数量和实名观演人。
3. 安装朋友发给你的“购票辅助”测试版 APK。
4. 使用真实项目测试可能生成待支付订单，请只在你能接受结果的项目上使用。

## 第一次打开

### 开启无障碍服务

1. 打开“购票辅助”。
2. 点击“前往系统设置开启”。
3. 找到“购票辅助页面识别”并开启。
4. 返回应用，确认页面显示“无障碍服务：已开启”。

这个权限用于读取大麦当前显示的按钮并执行受控点击。

### 允许通知

点击“允许运行通知”，在系统弹窗中选择“允许”。

通知会持续显示运行状态，并提供一个随时可用的“停止”入口。

## 填写购票目标

目标信息只有两项：

| 项目 | 怎么填 |
| --- | --- |
| 演出日期 | 点击日期选择器选择，例如 `2026-08-01`；不填写星期和时间 |
| 票档价格 | 只填数字，例如 `580`，不填写“看台”或“元” |

应用只按年月日匹配日期。大麦显示的星期、开场时间和“预售”等文字不参与匹配。
任务没有提交次数或运行时长上限，会持续尝试，直到进入付款页、你点击“停止”或触发安全暂停。

## 三种模式怎么选

| 模式 | 适合什么时候 | 使用方法 |
| --- | --- | --- |
| 只抢票 | 等待项目首次开售 | 显示悬浮窗后打开大麦项目详情页，再点悬浮“开始” |
| 只抢回流 | 项目已经开售，等待目标票档回流 | 打开目标场次和票档页，再点悬浮“开始” |
| 抢票后接回流 | 想先参加首次开售，失败后继续等待回流 | 从项目详情页开始，辅助会按安全规则切换阶段 |

第一次使用建议先选“只抢票”，并确保你能随时使用悬浮按钮停止任务。

## 开始使用

1. 再检查一次演出日期和票档价格。
2. 点击“保存配置并显示悬浮窗”。
3. 应用会回到后台，这是正常现象。
4. 你需要自己打开或切换到已经选好的大麦项目页。
5. 点击左上角悬浮窗中的“开始”；从此刻起应用才会识别并点击。

应用不会自己打开大麦，也不会在你点击悬浮“开始”之前识别页面。

## 运行时会看到什么

- **开始**：配置已经保存，尚未开始识别。
- **识别中**：你已点击开始，应用正在读取当前大麦页面。
- **暂停**：当前页面已经识别，可以临时暂停；恢复后会重新检查页面。
- **停止**：立即结束当前任务，清除等待中的动作。
- **安全暂停**：页面、日期或价格不一致，或者出现未知页面，
  辅助不会继续点击。
- **订单锁定**：已经进入收银台，自动操作结束，需要你自己确认是否付款。

## 正常效果

- “已预约”期间保持等待。
- “立即预订”可用且页面匹配时执行一次点击。
- 演出日期和票档价格一致后才继续。
- 出现登录、验证码、风控、设备校验或未知弹窗时停止自动操作。
- 到达收银台后停止，不点击付款。
- 你可以随时通过左上角按钮或通知停止。

实际能否买到票仍取决于平台页面、网络、库存和平台规则。辅助不会绕过平台限制，
也不能保证购票成功。

## 怎么立即停止

任选一种方法：

1. 点击左上角悬浮控件中的“停止”。
2. 下拉手机通知栏，点击“购票辅助正在运行”通知中的“停止”。

停止成功后，左上角悬浮控件和常驻通知都会消失。

## 常见情况

### “保存配置并显示悬浮窗”不能点击

检查：

- 无障碍服务是否显示“已开启”。
- 运行通知是否显示“已允许”。
- 是否已经选择演出日期并填写票档价格。

### 保存配置后没有打开大麦

这是正常设计。请你自己打开或切换到大麦。

### 运行后很快暂停

先看左上角提示。常见的可观察情况是：

- 当前日期和配置不一致。
- 页面中没有找到配置的票档价格。
- 出现登录、验证码、风控、设备验证或未知弹窗。
- 当前页面不是已经支持的大麦流程页面。

不要在不确定的页面强行继续，先停止任务并重新核对配置。

### 重新安装后提示无障碍未开启

重新进入手机系统的无障碍设置，开启“购票辅助页面识别”。

## 开始前最后检查

- [ ] 大麦已经登录。
- [ ] 大麦中的场次、票档、数量和观演人已经设置。
- [ ] 辅助中的演出日期和票档价格与大麦一致。
- [ ] 无障碍服务已开启。
- [ ] 通知已允许。
- [ ] 我知道打开大麦后还要点击悬浮“开始”。
- [ ] 我知道如何使用悬浮按钮或通知立即停止。
- [ ] 我知道进入收银台后需要自己决定是否付款。
